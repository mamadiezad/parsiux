رابط فارسی و RTL

یک گالری عملی برای دیدن خطاهایی که static lint به‌تنهایی نمی‌فهمد؛ متن مختلط، focus، قیمت، فرم و layout موبایل.

دیدن الگوها parsiux visual ./gallery/index.html --strict

Pattern library

هر نمونه، یک مسئله‌ی واقعی

درست01

قیمت، تخفیف و متن مختلط

عدد و واحد قابل اسکن هستند و شناسه‌های لاتین جای خودشان را حفظ می‌کنند.

غلط02

عددهای چسبیده و مبهم

واحد، تخفیف و شناسه در متن راست‌به‌چپ بدون isolation به‌هم می‌ریزند.

⌁

درست03

فیلترهای قابل wrap در موبایل

chipها در عرض کم می‌شکنند و action بازنشانی همیشه قابل دسترس می‌ماند.

فیلترهای فعال
display: flex; flex-wrap: wrap;
gap: .5rem;
غلط04

فیلترهای بریده‌شده

ردیف ثابت در صفحه‌ی کوچک، اطلاعات و actionها را از دید خارج می‌کند.

فیلترهای فعال
white-space: nowrap;
overflow: hidden;
درست05

focus واضح و هدف لمسی

کاربر کیبورد و موبایل می‌فهمد الان کجاست و می‌تواند action را با اطمینان لمس کند.

:focus-visible { outline: 3px solid #f79009; }
min-height: 44px;
غلط06

فرم بدون context

label مبهم، کنترل ریز و نبود focus واضح، خطا را برای همه بیشتر می‌کند.

outline: none;
height: 28px;
درست07

جدول responsive با اولویت اطلاعات

ستون‌های مهم حفظ شده‌اند و جزئیات ثانویه به ساختار قابل خواندن منتقل می‌شوند.

جدول فشرده‌ی دسکتاپ روی موبایل
